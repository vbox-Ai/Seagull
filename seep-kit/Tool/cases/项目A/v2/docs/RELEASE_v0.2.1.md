## Seep-Tool v0.2.1 — 修复 <项目A> 自定义授权信息显示

### 🐛 缺陷修复：<项目A> 关于框自定义授权信息显示

#### 根因定位与修复机理
- **原缺陷**：v0.2.0 仅将授权信息写入辅助配置文件 `xyplorer_patch.ini`，并试图在 DLL 运行期通过调用 `OLEAUT32!SysAllocString` 覆写内存全局变量。但宿主内部在自身生命周期内会由配置文件反复将授权全局重置，导致关于框未能读取到自定义信息；
- **新架构（双轨协同）**：
  1. **配置轨（主）**：在部署阶段通过 `WriteRegisterToConfigs` 直接向宿主配置文件（`%APPDATA%\<项目A>64\<项目A>.ini` 等）的 `[Register]` 段安全逐行写入 `Name`、`Code` 与 `dc`（自动备份 `.seep.bak`）。宿主启动时以原生逻辑载入，使**“关于”对话框稳定显示自定义授权用户名、密钥与 Lifetime License Enterprise 授权类型**；
  2. **内存轨（辅）**：`version.dll` 代理库移除运行期内存轮询，专注于 4 处底层控制流热补丁（标题栏试用横幅短路、试用文案长度归零、非免费提醒消解、关于框强切 Lifetime 分支）；
- **还原保障**：还原时优先由 `.seep.bak` 恢复原配置；无备份时清空 `[Register]` 授权段，100% 回落官方试用态。

### 🛡️ 质量门禁
- 部署 -> 原生配置载入 -> 全 UI 去试用 -> 60 秒稳定：PASS
- 还原 -> 纯净官方态回落 -> 试用横幅重新出现：PASS
